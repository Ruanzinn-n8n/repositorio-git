Afinal oque é DL, DT e DD?

DL
Definition List. DL é a tag que abre e fecha a lista de descrição
DT
Definition Term. DT é a tag do termo
DD
Definition Description. DD é a tag da descrição

Lista Não Ordenada

Marcada pelos seguintes simbolos usando o type após o ul ou il. Exemplo: ul type="example"

  • Disc ou vazio
  • Circle
  • Square

Lista Encadeada ou Mista

  • Circle
    • Vazado assim
  • Square
    • Obviamente quadrado

Lista Ordenada

  1. type="1" ou vazio para em números
  2. type="I" para em romano
  3. type="A" para em letras ou "a" para minúsculo

Lista Ordenada (começa onde quer)

Mesma coisa porém adicionando o start="x" ou value="x"

  1. Usando start="3" no ol
  2. Usando start="3" no ol
  3. Usando start="3" no ol

Ou...

  1. Usando value="3" no li> da minha escolha
  2. Usando value="3" no li> da minha escolha
  3. Usando value="3" no li> da minha escolha

OBS: o value começa a contar apartir do li que colocou, se eu coloco o value apartir do
segundo fica assim. Por exemplo:

  1. Usando value="4" no segundo li>
  2. Usando value="4" no segundo li>
  3. Usando value="4" no segundo li>
